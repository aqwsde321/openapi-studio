# 구현 계획

1. 독립 Vite/React/TypeScript 프로젝트와 script·태그 방식 초기화 API를 만든다.
2. 문서 검색·태그 접기·인증·시나리오 편집·YAML 파서를 구현한다.
3. 프로젝트/서버 관리 없이 embedded backend를 자동 workspace로 연결한다.
4. IndexedDB 시나리오/변수 저장과 브라우저 fetch 실행을 연결한다.
5. YAML 가져오기/다운로드, 로그인→값 연결→후속 요청, 새로고침 보존을 데모 backend와 테스트로 확인한다.

후속 범위: backend 기반 팀 공유 저장, 복수 서버 매핑, 추가 body 형식.
